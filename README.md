# Cupcake Gourmet — Sistema de Vendas Online

Projeto Integrador Transdisciplinar em Engenharia de Software II — Universidade Positivo
Autor: Jeander Kauan Przybeuka — RGM 40561992

Aplicação web responsiva (PWA) para venda online de uma loja de cupcakes gourmet:
o cliente navega pelo catálogo, monta o carrinho e fecha o pedido; a loja gerencia
o cardápio e a fila de pedidos.

## Estrutura do repositório

| Pasta | Conteúdo |
|---|---|
| `docs/01-escopo` | Escopo revisado (melhoria contínua sobre a PIT I) |
| `docs/02-uml` | Diagramas de casos de uso, classes, sequência e atividades |
| `docs/03-banco-de-dados` | Modelo conceitual, lógico, script físico (SQL) e dicionário de dados |
| `backend/` | API em Python + Flask, padrão MVC |
| `frontend/` | Interface em React + TypeScript + Tailwind CSS |
| `testes/` | Plano de testes, formulário de teste com usuários, laudos e evidências |

## Tecnologias

| Camada | Tecnologia |
|---|---|
| Front-end | React, TypeScript, Tailwind CSS (Vercel) |
| Back-end | Python 3, Flask, SQLAlchemy — padrão MVC (Render) |
| Banco de dados | PostgreSQL |
| Testes | pytest (back-end), Vitest (front-end) |
